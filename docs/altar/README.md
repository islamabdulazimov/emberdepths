# Алтарь и начало попытки

[Природный мир](natural-world.png) — маленький мир, seed 72419, без изменения тайлов, реальный рендер Player/World/алтаря. [Подготовка](preparation.png), [босс](fight.png), [сообщение без печати](missing-seal.png) — стенд с ровной тестовой площадкой и настоящими E/Esc/кликами Godot. Это проверка UI и появления, не оценка полного боя человеком и не замер FPS. Использовался программный Mesa llvmpipe.

Алтарь — оригинальные пиксельные прямоугольники в `scripts/boss_altar.gd`; иконка — `assets/icons/andrew_seal.svg`, оба CC0-1.0. Название предмета и временные ингредиенты вынесены из логики в data. Библиотеки не добавлялись.

Порядок ручной проверки и текущие ограничения — [README](../../README.md), результаты — последний раздел [HANDOFF](../../HANDOFF.md). Нового мира не требуется: старый получает алтарь, блоки и вещи не перестраиваются. Для сравнения новых seed есть `tests/altar_worlds_smoke.gd`.
