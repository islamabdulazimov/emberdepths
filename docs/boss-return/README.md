# Вход и возврат в бой

[Предупреждение](warning.png) показано до принятия участия: будущие ОЗ босса и прямое указание полного лечения. [После подтверждения](confirmed.png) видны прежние 44 ОЗ игрока и восстановленные 450 ОЗ Andrew. [Пауза](paused.png) показывает оставшееся окно возврата; [выбывший](withdrawn.png) не может обойти запрет после возрождения.

Снимки настоящего окна Godot, ввод E/Esc и клики — реальные. Ровная площадка и состав группы заданы стендом `tests/boss_return_render.gd`; это не запись игры людей через LAN. Пауза на 15 секунд в изображении задаётся тестовым шагом. Отдельные сетевые сценарии используют реальные ENet-разрывы и реальное ожидание более 60 секунд. FPS не измерялся, использовался программный Mesa llvmpipe.

Новой графики/звуков/сторонних библиотек в этом этапе нет. Оригинальные интерфейс/акторы/алтарь остаются из предыдущих этапов.
