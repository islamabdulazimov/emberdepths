# Расширенная внешность

Оригинальная одетая пиксельная графика CC0-1.0; исходник и лицензия — [assets/avatar](../../assets/avatar/README.md). Это графика прототипа, без индивидуальной художественной обработки каждого кадра.

- [Первая обычная мужская и женская модели рядом на настоящем грунте](normal-sample.png), [в броне](normal-armored-sample.png), [движение пары](normal-sample-motion.mp4). Масштаб тот же, что в игре: Camera2D 2×, одинаковые координаты пола и положение камеры. Этот образец проверен до расширения набора; итоговый рендер дополнительно отделяет ближнюю руку.
- [Итоговые шесть силуэтов и все причёски](fits-and-hair.png), [посадка полного комплекта](fitted-armor.png), [все модели в движении, 7 секунд](all-models-motion.mp4). Модель/телосложение подписаны, масштаб внутри каждой таблицы/пары одинаковый. Цвета и кожа специально различаются в таблице, чтобы показать палитру.
- [Настоящее меню: бег](creator-run.png), [удар](creator-attack.png).
- Новая внешность в действующем цикле: [упавшая](lifecycle-downed.png), [помощь](lifecycle-help.png), [после поднятия](lifecycle-revived.png).

Видео снято последовательностью кадров настоящего Player, 60 кадров/с. Фазы в сравнительном обзоре задаются стендом: это позволяет сравнить одинаковые действия, но не заменяет игру и не измеряет FPS. Клавиши, движение/прыжок/удар/перекат и помощь проверены отдельными тестами в настоящем окне Godot; сетевые данные — четырьмя ENet-процессами.

Для ручной проверки: F5 → Новая игра. Сравните обычные мужскую/женскую модели, затем телосложения, длинные волосы и цвета. Переключите Покой/Бег/Удар. Создайте персонажа, проверьте A/D, Space, ЛКМ с мечом, Shift с Узлом странника, броню и получение урона. Сохраните, выйдите через P и продолжите: внешность и вещи должны совпасть. В кооперативе каждый видит выбранную внешность товарища; между физическими ПК это ещё нужно проверить.

Автоматические стенды и результаты перечислены в последнем разделе [HANDOFF](../../HANDOFF.md). Новые персонажи используют расширенные поля; старые получают обычное телосложение и исходный тёмный цвет волос, без потери вещей. Изменить уже созданную внешность через меню пока нельзя.
