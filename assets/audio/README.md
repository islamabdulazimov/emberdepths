# Шелест листвы

`leaf_rustle.wav` — оригинальный синтезированный шум листвы, созданный для
Emberdepths скриптом `tools/generate_leaf_rustle.py`. Исходник — этот генератор:
фиксированный псевдослучайный шум, фильтры, амплитудные огибающие и склейка петли.
Записей, чужих семплов и сторонних библиотек нет.

Аудиофайл и генератор предоставлены под **CC0 1.0 Universal**:
https://creativecommons.org/publicdomain/zero/1.0/
Можно использовать, изменять и распространять без указания авторства.

Mono PCM16, 22050 Hz. Повторная генерация: `python tools/generate_leaf_rustle.py`.
Проект воспроизводит один общий тихий цикл с затуханием от расстояния до деревьев;
ограничение громкости находится в `data/trees.gd`. Это технический звук окружения,
не полевая запись. Финальный уровень громкости следует оценить на слух в игре.

## Гул Гулоклюва

`hollow_hum.wav` — оригинальный синтезированный нарастающий тон с двумя гармониками,
созданный `tools/generate_hollow_hum.py`, без записей и сторонних семплов.
Файл и генератор также **CC0 1.0 Universal**. Mono PCM16,22050 Hz,0,9 с.
Повторная генерация: `python3 tools/generate_hollow_hum.py` (stdlib).
Игра воспроизводит его в AudioStreamPlayer2D при подготовке Гулоклюва,
с затуханием до 260 px и уровнем−26 dB; клиенты запускают предупреждение по полученной
фазе. В облачных проверках использован Dummy audio: громкость и характер гула
нужно оценить на слух в игре.
